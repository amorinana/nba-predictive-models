# Previsão de Jogadores Superfaturados na NBA 🏀

**Criação de Ana Caroline e Carlos Eduardo.**

## Sobre o Projeto

Este projeto tem como objetivo aplicar técnicas de aprendizado de máquina para prever se um jogador da NBA está superfaturado ou não, com base em indicadores de desempenho e informações salariais.
A proposta combina análise estatística, engenharia de atributos e modelagem preditiva para identificar padrões de valorização e auxiliar em decisões mais inteligentes sobre contratações e investimentos no esporte.

## Metodologia

O processo foi dividido em etapas:

Coleta e tratamento dos dados — dados históricos de jogadores, desempenho em quadra e salários.

Análise exploratória (EDA) — identificação de correlações e tendências entre performance e remuneração.

Criação de variáveis — métricas como Efficiency Rating, Win Shares, Points per Game, entre outras.

Treinamento de modelos — comparação entre algoritmos (como Random Forest, CatBoost e Regressão Logística).

Avaliação de performance — métricas como Accuracy, F1-Score e ROC-AUC para medir a precisão das previsões.

Interpretação dos resultados — análise dos fatores que mais influenciam na classificação de um jogador como superfaturado.
